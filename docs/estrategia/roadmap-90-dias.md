# Roadmap a 90 días

🎯 Cómo pasar de "el sistema está instalado" a "el sistema es como trabajo". Con las **5 horas de acompañamiento** repartidas donde más rinden.

---

## Principio

**Una cosa a la vez, hasta que sea automática.** El error clásico es implementar las nueve automatizaciones el primer mes: al segundo mes no se usa ninguna y se vuelve a lo de antes.

Cada fase termina cuando la anterior ya no se piensa.

---

# Fase 1 · Días 1–14 — Renderizado

**El objetivo:** que un render deje de ser un problema de agenda.

### Semana 1

| | |
|---|---|
| **Instalar** | Claude Pro, Node.js, descargar el repositorio |
| **Crear** | Proyecto *Render Studio* en Claude |
| **Probar** | Un espacio, de principio a fin. Un baño |
| **Medir** | Cuánto tardaste. Anótalo. Es tu línea base |

> 📞 **Sesión 1 de acompañamiento — 1 hora.** Configuración de Claude, creación del primer Proyecto, y el primer render juntos en vivo. Es la sesión que más rinde: ver el flujo una vez completo vale más que leer toda la documentación.

### Semana 2

| | |
|---|---|
| **Repetir** | Tres espacios más, tú solo |
| **Practicar** | La biblioteca de correcciones. Provoca los errores a propósito |
| **Guardar** | Los prompts que funcionaron, en `datos/prompts-guardados/` |
| **Ajustar** | Lo que corrijas dos veces, súbelo a las Instructions |

**Terminas la fase cuando:** puedes producir un render aprobado en menos de 30 minutos sin volver a abrir la documentación.

## Reparto de las 5 horas

| Sesión | Cuándo | Sobre qué |
|---|---|---|
| 1 | Semana 1 | Configuración + primer render en vivo |
| 2 | Semana 3 | Primer proyecto real a JSON |
| 3 | Semana 6 | Precios reales y flujo comercial |
| 4 | Semana 9 | Sesión de contenido completa |
| 5 | Semana 11 | Con Juan Esteban |

> Este reparto es una propuesta. Si algo se atasca, la sesión se usa donde haga falta. Lo que no conviene es gastarlas todas el primer mes: **el mayor valor de una sesión aparece cuando ya intentaste hacerlo solo**, porque entonces las preguntas son las reales.

Eso fue lo que dijiste que necesitabas. Es la única métrica que decide si esto funcionó.

## Qué puede salir mal

| Riesgo | Señal temprana | Qué hacer |
|---|---|---|
| **Implementar todo de una** | Semana 2 y hay seis Proyectos creados y ninguno usado | Volver a uno. El de render |
| **Abandonar en la semana 3** | Dos semanas sin abrir Claude | Retomar solo con el flujo de render. Es el que se paga solo |
| **No cargar datos reales** | Se sigue cotizando a mano "por ahora" | Bloquear una hora para cargar precios. Sin eso el cotizador no sirve |
| **Juan no entra** | Sigues haciendo tú todos los renders al día 60 | Adelantar la sesión 5 |
| **Enviar sin revisar** | Un error llega a un cliente | Corregir de frente y volver a la regla: nada sale sin revisión |
